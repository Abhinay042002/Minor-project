# Standard Essentials — Frontend E-Commerce Website (HTML, CSS, JS, React.js & Tailwind CSS)

This project is a 100% frontend web application using **HTML5**, **CSS3 / Tailwind CSS**, **JavaScript (ES6)**, and **React.js**. All cart items, wishlist items, reviews, orders, and admin catalog updates are stored directly in the browser using `localStorage` (no backend server or external database required).

## Files Included
- `index.html` — Main HTML5 page
- `src/style.css` — CSS3 & Tailwind CSS styles
- `src/main.jsx` — JavaScript entry point mounting React
- `src/App.jsx` — Complete React.js + Tailwind CSS storefront and separated Admin portal
- `tailwind.config.js` & `package.json` — Frontend configuration
- `public/images/` — Product photos

## How to Run in VS Code
```bash
npm install
npm run dev
```
